# Genome-Wide Scan for Transmission Ratio Distortion in MoBa

Code for:

**"Genome-Wide Scan for Transmission Ratio Distortion Across 43,829 Genotyped Trios From The Norwegian Mother, Father and Child Cohort Study (MoBa) Rules Out Moderate Levels of Distortion at Common Variants but Prioritises Meiosis-Related Genes for Follow-Up"**

---

## Overview

This repository contains scripts used to perform:

- Genome-wide Transmission Disequilibrium Test (TDT) (example script)
- Parent-of-origin TDT (POO-TDT) (example script)
- Offspring sex–stratified TDT (example script)
- DENTIST-based summary statistic QC (example script)
- Multi-locus TDT analyses (example script)
- Power analyses 
- HWE simulation
- DENTIST simulation
- Multi-locus TDT simulation

This repository also contains TDT summary statistics from the four TDT analyses in MoBa:

- Combined (all offspring, autosomes + X)
- Male-stratified (male offspring only, autosomes + X)
- Female-stratified (female offspring only, autosomes + X)
- Parent-of-origin (all offspring, autosomes only)
